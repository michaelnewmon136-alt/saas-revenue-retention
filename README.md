# SaaS Revenue Retention: MRR, Churn and Net Revenue Retention

> **All data in this project is synthetic.** It is randomly generated by a script in this repository. Nothing here describes a real company, and no result should be read as a finding about real customers.

## Business question

A fictional B2B SaaS company is adding new customers, but its recurring revenue growth is slowing. Are customers leaving, downgrading, or not expanding fast enough?

## The MRR bridge

Closing MRR = Opening MRR + New + Expansion + Reactivation - Contraction - Churn

The answer key checks this equation for every month.

## Planted patterns (known in advance)

Because the data is simulated, these patterns were built in on purpose:

- SMB customers churn more than larger customers.
- New customers churn more in their first 6 months.
- Signups grow over time.

Finding these later tests whether the pipeline works. It is not a discovery about a real business.

## How to reproduce

1. Install Python 3.13.
2. Create a virtual environment and install: numpy, pandas, duckdb.
3. Run: python data_generator/generate_data.py
4. Run: python analysis/answer_key.py

The random seed is fixed at 42, so everyone gets identical data.

## Limitations

- Synthetic data cannot show how real customers behave.
- Correlations found here do not prove cause and effect.
